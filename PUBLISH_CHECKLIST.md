## 🔧 Этап 3: GitHub настройка (15 мин)

### На GitHub.com

#### Шаг 1: Создание репозитория
- [ ] Заходим на GitHub.com
- [ ] Нажимаем "New" → "New repository"
- [ ] Название: `it-team-office` (или другое)
- [ ] Описание: "3D IT Team Office - Interactive WebGL Scene"
- [ ] Public (чтобы все видели)
- [ ] Нажимаем "Create repository"

#### Шаг 2: Добавление кода
В терминале выполняем:
```bash
git remote add origin https://github.com/YOUR_USERNAME/it-team-office.git
git branch -M main
git push -u origin main
```

- [ ] Код загружен на GitHub
- [ ] Видимо на GitHub.com в браузере

#### Шаг 3: Установка gh-pages пакета
```bash
npm install --save-dev gh-pages
```
- [ ] Пакет установлен (проверяем в package.json)

#### Шаг 4: Обновление package.json
Добавляем в `package.json`:
```json
{
  "homepage": "https://YOUR_USERNAME.github.io/it-team-office",
  "scripts": {
    "deploy": "gh-pages -d dist"
  }
}
```

- [ ] Добавлена строка `"homepage"`
- [ ] Добавлен скрипт `"deploy"`
- [ ] Заменили USERNAME и REPONAME на реальные

#### Шаг 5: Сборка и деплой
```bash
npm run build
npm run deploy
```

- [ ] Построился production (`dist/` создана)
- [ ] Команда deploy выполнена без ошибок
- [ ] На GitHub видна новая ветка `gh-pages`

### В GitHub Settings

#### Шаг 1: Pages настройка
- [ ] Открываем репозиторий на GitHub
- [ ] Нажимаем Settings (шестеренка)
- [ ] В левом меню ищем "Pages"

#### Шаг 2: Source выбор
- [ ] Находим "Build and deployment" → "Source"
- [ ] Выбираем "Deploy from a branch"
- [ ] Branch: `gh-pages`
- [ ] Folder: `/ (root)`
- [ ] Нажимаем "Save"

#### Шаг 3: Ожидание развертывания
- [ ] Ждём 1-5 минут
- [ ] На странице Settings → Pages должна быть зеленая галочка
- [ ] Строка "Your site is live at https://..."

## 🎓 Если что-то не работает

### GitHub Pages не включается
- [ ] Проверьте Settings → Pages
- [ ] Выбирали ветку `gh-pages`?
- [ ] Выбирали folder `/ (root)`?
- [ ] Нажали "Save"?

### 404 ошибка при открытии
- [ ] Правильная ли ссылка в браузере?
- [ ] Прошло ли 5 минут с момента деплоя?
- [ ] Ветка `gh-pages` существует на GitHub?

### Черный экран вместо сцены
- [ ] Откройте F12 → Console
- [ ] Какие ошибки показывает?
- [ ] Поддерживает ли браузер WebGL 2.0?
- [ ] Читайте [DEVELOPMENT_GUIDE.md](DEVELOPMENT_GUIDE.md) раздел "Debugging"

### Сайт медленный
- [ ] Это нормально для первой загрузки
- [ ] После загрузки FPS должен быть ≥ 50
- [ ] На слабых ПК может быть медленнее

### Мониторы не светят
- [ ] Проверьте браузер (Chrome лучше)
- [ ] Перезагрузите страницу (Ctrl+Shift+R)
- [ ] Проверьте что WebGL работает на сайте https://get.webgl.org/
