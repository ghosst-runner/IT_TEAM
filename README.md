# 🚀 IT Team Office - 3D Interactive Scene

Интерактивный 3D сайт про нашу ИТ-команду в неоновом киберпанк-стиле с использованием WebGL графики.

## 📋 Описание

Это веб-приложение представляет офисное пространство нашей IT-команды в 3D-формате. Вы можете:

- **Свободно двигать камеру** - кликните и тащите мышью для вращения
- **Приблизиться/отдалиться** - используйте колесо мыши для зума
- **Рассмотреть деталь** - наведите на мониторы, ПК и другие элементы

## 📁 Структура проекта

```
src/
├── components/
│   ├── Scene.tsx              # Главная сцена с расстановкой персонажей
│   ├── Room.tsx               # Комната с неоновым оформлением
│   ├── PixelCharacter.tsx      # Пиксельные 3D персонажи
│   ├── Furniture.tsx           # Мебель (столы, стулья, мониторы, ПК)
│   ├── Lights.tsx              # Неоновое освещение
│   └── CameraController.tsx    # Управление камерой
├── App.tsx                     # Главный компонент
├── main.tsx                    # Точка входа
└── index.css                   # Глобальные стили
```

## 🎮 Управление камерой

| Действие | Что делает |
|----------|-----------|
| 🖱️ Левая кнопка мыши + движение | Вращение камеры |
| 🖱️ Правая кнопка мыши + движение | Вращение камеры |
| 🔄 Колесо мыши вверх | Приблизить |
| 🔄 Колесо мыши вниз | Отдалить |

## 🚀 Установка и запуск

### Локально

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для production
npm run build

# Превью production версии
npm run preview
```

### На GitHub Pages

1. Сбилдите проект: `npm run build`
2. Содержимое папки `dist/` загрузите в ветку `gh-pages`
3. Включите GitHub Pages в настройках репозитория
